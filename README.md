## Topics Covered
### 1. Difference Between the Internet and the Web
- **Internet**: A global system of interconnected computer networks using TCP/IP protocols.  
- **Web**: A collection of websites and pages accessed via browsers like Chrome.  

### 2. What is Web Development?
- Creating, building, and maintaining websites and web applications.  
- Covers **Frontend**, **Backend**, and **Full Stack** development.  

### 3. Jobs in Web Development
- Full Stack Developer  
- Frontend Developer  
- Backend Developer  
- UI/UX Designer  
- Project Manager  
- Mobile Developer  
- Quality Assurance / Quality Control  
- DevOps Engineer
